# MZLFF / PHANTASMAGORIA — фан-сайт

Статический сайт об альбоме: история, персонажи, треклист и плеер с построчным текстом. Для публикации сборка и сервер приложений не нужны; `index.html` должен оставаться в корне репозитория.

## Локальный запуск и публикация

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для GitHub Pages выберите в **Settings → Pages** публикацию из нужной ветки и папку `/ (root)`. Пакеты npm нужны только для разработки и тестов, а не для работы сайта.

## Как работает плеер

- Основной источник — MP3 из [релиза `audio-v1`](https://github.com/Cnizroman/PHANTASMAGORIA/releases/tag/audio-v1). Их адрес задан константой `RELEASE` в `script.js`, имена файлов совпадают с ключами треков. Браузер воспроизводит файлы обычным `<audio>` без Web Audio: это избегает заглушения кросс-доменных файлов из-за CORS. Если перенести или удалить релиз, нужно обновить адреса.
- По кнопке «ВИДЕО» отдельно загружается YouTube IFrame API и открывается соответствующее официальное видео. Доступность зависит от сети, региона и разрешения на встраивание. При ошибке есть ссылка на ролик и возврат к аудио.
- Строки подсвечиваются по фактической позиции активного источника. Нажатие на строку перематывает к ней. При необходимости кнопки `−0.5` и `+0.5` показывают текст соответственно раньше или позже; значение сохраняется отдельно для каждого трека в браузере, нажатие на значение сбрасывает его. Ручную прокрутку можно отменить кнопкой «К текущей строке».
- Тексты и построчные метки взяты из пользовательской базы [LRCLIB](https://lrclib.net/) для альбомных версий. Они могут содержать неточности или отличаться от других версий записи. Значки между строками обозначают инструментальные паузы.

Исходные метки лежат в `lyrics/*.lrc`. После изменений пересоберите локальный, загружаемый без запросов `lyrics.js`:

```sh
node scripts/build-lyrics.js
```

## Изображения и источники

Кадры персонажей взяты из официальных видео MZLFF: [«phantasmagoria»](https://www.youtube.com/watch?v=JFHYBcEt4mg), [«свободное падение»](https://www.youtube.com/watch?v=6PIzbzYEGwM) и [«комната смеха»](https://www.youtube.com/watch?v=AgWgoLZj6So). В оформлении треков также использованы кадры [«карусель»](https://www.youtube.com/watch?v=-ZcITdWVap0) и [«автодром»](https://www.youtube.com/watch?v=67HBrJSbjSM). Другие ссылки и пояснения приведены на самом сайте. Это неофициальный фан-проект; права на музыку, видео и изображения принадлежат их правообладателям.

Шрифты Manrope, Playfair Display и IBM Plex Mono хранятся локально в `assets/fonts/`; тексты лицензий находятся там же.

## Проверки

Для тестов нужны Node.js и npm:

```sh
npm ci
npm test                       # синхронизация и проверка сборки LRC
npx playwright install chromium
npm run test:e2e               # браузерные сценарии и axe-core
```

Браузерные тесты воспроизводят локально сгенерированный WAV через настоящий `<audio>` и имитируют YouTube API; они не скачивают записи альбома и не заменяют прослушивание реальных MP3 или проверку настоящего встроенного YouTube в доступной сети.
