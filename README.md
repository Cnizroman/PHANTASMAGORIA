# MZLFF — PHANTASMAGORIA

**Интерактивный фан-сайт, посвящённый альбому PHANTASMAGORIA.** Музыка, история, персонажи и визуальный мир альбома собраны в одном небольшом веб-проекте.

## О проекте

PHANTASMAGORIA — сайт-путешествие по концептуальному альбому MZLFF, выпущенному 26 сентября 2025 года. В основе оформления — образ парка аттракционов: у каждого раздела, трека и визуального элемента есть своё место в общей истории.

Задача проекта — не просто перечислить песни, а собрать материалы об альбоме в цельное интерактивное пространство: от знакомства с его сюжетом и персонажами до прослушивания композиций с синхронизированными текстами.

## Возможности

- **История альбома.** Отдельный раздел о концепции, образах и сюжетной линии PHANTASMAGORIA.
- **Персонажи.** Визуальные материалы и описания героев, основанные на клипах и текстах песен. Интерпретации на сайте не следует считать официальным каноном.
- **Треклист из восьми композиций.** С описаниями, продолжительностью и переходом к выбранной песне.
- **Встроенный плеер.** Можно выбрать аудиоверсию или видеоисточник YouTube, управлять воспроизведением, громкостью, скоростью, перемоткой, повтором и случайным порядком.
- **Синхронизированные тексты.** Строки подсвечиваются по ходу воспроизведения; нажатие на строку переносит к соответствующему моменту.
- **Режим чтения.** Текст раскрывается на весь экран в отдельном модальном окне: крупные строки, собственный транспорт и закрытие по `Esc`.
- **Скорость и звук.** Скорость переключается между 0,75×, 1× и 1,25×, а кнопка динамика мгновенно выключает и возвращает звук.
- **Настройка синхронизации.** Сдвиг текста меняется с шагом 0,5 секунды и запоминается отдельно для каждого трека.
- **Личный прогресс.** Сайт сохраняет в браузере прослушанную часть композиций и показывает, какие треки уже пройдены. Когда пройдены все восемь, на входном билете появляется штамп.
- **Маршрут тура.** В разделе тура собраны все 28 концертов и 24 города осеннего тура — по официальному постеру, без мелкого шрифта.
- **Адаптивный интерфейс.** Страницей можно пользоваться на компьютере, планшете и телефоне; меню, плеер и текст перестраиваются под ширину экрана.
- **Быстрая загрузка.** Иллюстрации отдаются в WebP с резервным JPEG/PNG, аудио следующего трека подгружается только при наведении или фокусе.
- **Доступность.** Клавиатурная навигация, статусы для скринридеров, видимый фокус и цели нажатия не меньше 24 px. Браузерные тесты проверяют страницу по axe-core на соответствие WCAG 2.0–2.2 уровней A и AA.
- **Поддержка автора.** На главном экране и в подвале сайта есть ссылка на DonationAlerts.

## Технологии

Проект сделан без фронтенд-фреймворков и серверной части. Основу составляют:

- HTML5 — структура и содержимое страницы;
- CSS3 — оформление, адаптивная сетка и анимации;
- JavaScript — плеер, навигация, работа с текстами и интерактивные элементы;
- YouTube IFrame API — переключение на видеоверсию композиций;
- нативный `<dialog>` — полноэкранный режим чтения текста;
- WebP и `<picture>` — облегчённые версии иллюстраций с резервными форматами;
- `localStorage` — локальное сохранение прогресса, громкости, скорости и настроек синхронизации;
- Playwright и axe-core — браузерные проверки и тестирование доступности.

## Запуск локально

Для обычного просмотра не нужно устанавливать зависимости или собирать проект. Достаточно запустить локальный HTTP-сервер из корневой папки репозитория.

**Python:**

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000/`.

Можно использовать любой другой статический HTTP-сервер. Запуск через сервер предпочтительнее открытия `index.html` напрямую: некоторые возможности браузера и загрузка внешних ресурсов могут вести себя по-разному при `file://`.

## Публикация на GitHub Pages

1. Открой репозиторий **Settings → Pages**.
2. В разделе **Build and deployment** выбери публикацию из ветки.
3. Выбери ветку `main` и папку `/ (root)`.
4. Сохрани настройки. После публикации сайт будет доступен по адресу `https://cnizroman.github.io/PHANTASMAGORIA/`.

`index.html` должен оставаться в корне выбранной папки. Проект является статическим сайтом и не требует отдельного backend-сервера для основных функций.

## Аудио и видео

MP3-файлы загружаются из [GitHub Release `audio-v1`](https://github.com/Cnizroman/PHANTASMAGORIA/releases/tag/audio-v1). Базовый адрес релиза задан в `script.js` в константе `RELEASE`. Если аудиофайлы будут перенесены в другой релиз или переименованы, нужно обновить адрес и проверить соответствие имён файлов.

Видеоверсия треков открывается через YouTube IFrame API. Доступность встроенного видео зависит от сети, региональных ограничений и настроек самого ролика. В плеере предусмотрено переключение между аудио и видеоисточником.

## Тексты песен и синхронизация

Исходные таймкоды находятся в каталоге `lyrics/` в формате LRC. Файл `lyrics.js` — готовый JavaScript-набор, который браузер загружает без отдельной сборки.

После изменения LRC-файлов пересобери `lyrics.js`:

```bash
node scripts/build-lyrics.js
```

В плеере можно вручную подстроить отображение строк кнопками `−0.5` и `+0.5`; `0.0 с` сбрасывает сдвиг. Настройка хранится локально в браузере отдельно для каждого трека.

## Управление плеером

| Клавиша | Действие |
| --- | --- |
| `Пробел` | Воспроизвести / пауза после начала прослушивания |
| `←` | Предыдущий трек |
| `→` | Следующий трек |
| `M` | Выключить / включить звук |
| `Esc` | Закрыть полноэкранный текст |

На мобильных устройствах и при использовании клавиатуры также доступны экранные элементы управления. Кнопка «Развернуть» в шапке текста открывает режим чтения: в нём доступны переключение треков, пауза и текущее время. Кнопки скорости находятся рядом с громкостью и запоминаются между визитами.

## Тестирование

Тесты нужны только для разработки. Установи Node.js, затем выполни:

```bash
npm ci
npm test
```

Для браузерных тестов установи Chromium для Playwright и запусти:

```bash
npx playwright install chromium
npm run test:e2e
```

Unit-тесты проверяют вспомогательную логику синхронизации и подготовки текстов. E2E-тесты проверяют поведение страницы в браузере. Они используют тестовые медиа-данные и не заменяют ручную проверку реальных MP3, YouTube и доступности внешних сервисов.
